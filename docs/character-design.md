# Character Development

## Objective
Develop original and recognizable characters
for the Toonami animation universe.

## Character Design Elements
- Character appearance
- Facial expressions
- Body proportions
- Personality
- Movement and poses
- Voice and dialogue

## Consistency Guidelines
- Maintain original character proportions.
- Preserve the established art style.
- Keep character colors consistent.
- Document all important poses.
