# Toonami – Animation Studio

An independent 2D animation and storytelling project.

## About the Project

Toonami is a creative project focused on producing entertaining animated stories for digital platforms.

The project explores storytelling, character development, animation production and creative content creation.

## Objectives

- Develop original animated stories.
- Create and refine original characters.
- Explore 2D animation workflows.
- Improve storytelling and visual production.
- Build a consistent animation production pipeline.

## Tools & Technologies

- Blender
- Unreal Engine
- 2D Animation Software
- Digital Illustration Tools
